How it works

Three steps. You always get your build, and you can learn as it grows.

1

Say what you want

Describe an app, a report, a website or a circuit in plain words. Plan first if you like.

2

It builds in stages

The AI splits the work into stages and builds while you watch the app take shape.

3

Learn each stage

Short lessons, a quiz, then you rewrite it yourself. Or tap Build only to skip the teaching.

Not just answers. Understanding.

Most tools hand you code you can't explain. Mentor teaches the new ideas in each stage, then asks you to write them yourself.

  • Short lessons with a live example you can edit
  • Serious quizzes with no hints
  • Battle mode: rewrite it from memory, paste turned off
  • Compare your code with the AI's and learn the difference

Software and hardware, one workspace.

Design a board, write the firmware, and run them together before you build anything real.

  • Dense board view and real KiCad editing
  • Simulate firmware and circuits, with the AI beside you
  • Pick only the tools you need
  • Simulation is a strong check, not a guarantee of real-world results

Questions

Do I have to learn to use it?

No. Choose Build only for a chat and it simply builds. Learning is always one tap away.

Can I turn Mentor off?

Yes. It is on by default, and you can switch it off in Settings.

Is my data private?

Temporary chats are not saved or used for export. Read our privacy page for the full details.
