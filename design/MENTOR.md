# Mentor - "Learn as you build" (agents: read before changing AI replies, Settings, chat or onboarding)

## Core promise
Mentor is ON by default for everyone. Settings > Learning > Mentor sets the default. Never remove the switch, never turn it off for a user, never block building behind a lesson.

## Lives inside the normal chat (no separate build space)
- Composer has a small "Teach & build" chip next to the mode pill. Tap: Teach & build (default) or Build only. Build only is for THIS chat only; the Settings default is unchanged.
- Plan / Balanced / Build modes are separate and stay as they are. Plan = talk through and refine the plan before building.
- Slogan "Learn as you build" shows under the app name on splash, onboarding slide 1, sign-up and the Home top bar.

## The learning loop (per stage, not per line)
The AI splits the build into stages (about 3 to 6). When a stage finishes, a card appears in the chat: "Stage N: X new ideas. Learn this stage | Keep building". Building continues while the user learns.
1. Teach: short lesson per NEW concept only (what it is, why it exists, an editable live example, the common mistake, same idea in other languages/frameworks). True beginners start from fundamentals.
2. Quiz: serious, no hints (predict the output, spot the bug, fill the line). Skippable.
3. Rewrite (battle mode): the user sees what the code must DO, not the code, and writes it from memory. Paste, copy, cut, drag-drop and right-click are blocked in this editor. No automatic hints, no countdown timer. Tests run the code. "Ask for help" exists and marks the attempt as assisted.
4. Review: compare the user's code with the AI's version and teach good and bad habits. Then the next stage unlocks.
The AI's quality judgments are suggestions; link to official docs for facts.

## Rewards
- Bonus build credits only for passing a rewrite WITHOUT help, verified by sandbox tests.
- Mentor rewards have their OWN daily cap per user and a global daily reward pool, separate from the chat cap. Smaller reward for repeating a concept. Pool pauses when empty.
- Randomize task variants so answers cannot be pasted. Accept that copy-blocking is only friction (another device or tab still works).
- No streaks, guilt or pressure. The main reward is the app the user built and understood.

## Cost control
Write lessons for common concepts once and reuse them. Quizzes come from a bank and are graded by tests, not the model. Use the model only for the plan, stage splitting and the final review. Count Mentor tokens in credits.

## Progress
Settings > What you've learned: concepts, level, recent lessons.

## Limits
Do not claim Mentor makes anyone an expert. Measure with real beginners before promising results. Later: link lessons to practice challenges in the arena app.
